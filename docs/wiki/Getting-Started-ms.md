# Bermula

## Keperluan

Python 3.13 atau lebih baharu dan `pytest` untuk ujian. Tiada kebergantungan semasa larian.

## Persediaan

```bash
python -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
```

## Jalankan

```bash
python -m guess_the_number
```

## Ujian

```bash
python -m pytest
```
